How to Encrypt & Decrypt
1 Encryption — Lock Your File
1. Upload any file using the Upload & Encrypt form on the left
2. A backup is created in your personal folder then Fernet AES-128 encryption is applied
3. A unique encryption key is generated — this is your only way to recover the file
4. The original file is removed (simulating real ransomware behavior)
5. The key is also emailed to your registered email for backup
2 Decryption — Unlock & Restore
1. Select the encrypted .locked file from the list under Decrypt with Key
2. Paste or type the encryption key you saved when you encrypted the file
3. The system verifies the key and decrypts using Fernet AES-128
4. Your original file is restored — download it from the Download Decrypted File section
⚠️ Critical: Without the encryption key, your file cannot be decrypted — it will be permanently lost. Always save the key immediately after encryption. The key is also sent to your registered email as a backup.
💡 Educational Purpose: This module simulates ransomware behavior for cybersecurity awareness training. It demonstrates how ransomware encrypts files and why regular backups are essential for recovery.
